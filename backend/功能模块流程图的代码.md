# **查重模块**

**graph** TD

    Start((开始)) **-->** AdminLogin[管理员登录]

    AdminLogin **-->** InputTask[3.1 输入拟建信息]

    %% 输入数据与参数

    InputTask **-->** DataFill[填写: 拟建名称 / 核心关键词 / 摘要大纲]

    DataFill **-->** SetThreshold[设置相似度预警阈值: 如 百分之60]

    %% 系统自动比对动作

    SetThreshold **-->** SearchEngine[3.2 系统检索动作]

    SearchEngine **-->** QueryDB[查询后端标准基准库: 模块1]

    %% 比对算法核心 (侧重题目信息)

    QueryDB **-->** SimilarityCalc[相似性算法计算]

    SimilarityCalc **-->** TitleMatch[题目/名称语义相似度匹配]

    TitleMatch **-->** KeywordMatch[关键词覆盖度匹配]

    KeywordMatch **-->** ScoreGen[生成综合重合百分比]

    %% 结果判定逻辑

    ScoreGen **-->** ResultJudge{重合度与阈值比对}

    ResultJudge **--** "重合度 < 阈值 (低风险)" **-->** SuggestA[结论: 建议立项]

    ResultJudge **--** "阈值 ≤ 重合度 < 85% (中风险)" **-->** SuggestB[结论: 建议修改后再立项]

    ResultJudge **--** "重合度 ≥ 85% (高风险)" **-->** SuggestC[结论: 不建议立项]

    %% 输出冲突建议

    SuggestA **&** SuggestB **&** SuggestC **-->** ConflictDetail[生成冲突/覆盖详细建议]

    ConflictDetail **-->** MapExisting[指出已覆盖的具体存量标准号及名称]

    %% 查重报告生成

    MapExisting **-->** ReportGen[3.3 查重报告生成]

    ReportGen **-->** Preview[界面实时预览: 重合对比列表 + 结论意见]

    Preview **-->** ExportPDF[导出 PDF 版查重报告]

    ExportPDF **-->** Archive[(存入查重历史记录库)]

    Archive **-->** End((结束))
