# 后端未实现的接口信息汇总

本文档面向成员五四个模块的前端规划，将「**界面与流程需要的数据能力**」与现行《[后端接口说明文档.md](../../后端接口说明文档.md)》逐项对照，**仅罗列当前说明文档无法支撑或无法完整支撑的缺失功能**（不写具体 URL、技术实现或框架选型）。

**说明**：

- **「未实现」**在此指：对**前端按说明文档联调**而言，缺少可依赖的 HTTP/WebSocket 契约，或仅有只读片段、无法闭环。**不代表**后端代码库中一定不存在相关逻辑（可能仅有 Admin、脚本或未文档化接口）。
- 各模块详细「已有接口」见同目录 [01-standard-library.md](./01-standard-library.md)～[04-system-security-audit.md](./04-system-security-audit.md) 第 8 节。

## 1. 标准库管理模块

### 1.1 行业分类体系（ICS / CCS / 自定义标签）

- **独立维护能力**：分类树的增删改、排序、启用/禁用；自定义标签体系的管理。
- **与标准绑定的校验**：标准必须挂载到有效分类节点；批量导入时的分类校验与错误行反馈。
- **说明文档现状**：`detail-info` 等接口仅能提供 CCS/ICS **展示级**字段，**无**独立分类资源与树形维护契约。

### 1.2 数据正文库（全量结构化正文）

- **章节 / 条款 / 规范性引用 / 附录等**结构化正文的**持久化与版本**（若产品与规划要求独立于「仅前言差异」）。
- **技术指标结构化**（参数、算子、标准值等）在正文侧的**完整读写、检索**，与仅索引表只读列表的边界需产品界定。
- **说明文档现状**：前言相关有解析状态与上传；整本 PDF 有下载；**无**与「全文拆解」各区块一一对应的、完整的结构化正文管理 API 清单（索引表等为读接口片段）。

### 1.3 标准谱系（写操作与闭环）

- **在业务界面内**新增、修改、废止标准间关系（替代链等），并依赖后端**写库**与**被替代标准状态联动**（流程图中有「系统自动变更被替代标准状态」）。
- **说明文档现状**：族谱查询、关系/替代表**读**接口存在；是否在 `/api` 下暴露**写**、是否仅能通过 Django Admin 或 DRF 通用 CRUD 完成，**说明文档未单独描述**写路径与权限，前端无法仅凭文档闭环「谱系维护页」。

### 1.4 查询统计（扩展）

- **跨库复杂条件**下的组合检索、报表统计、**受控导出**（字段、权限、异步导出任务），若超出关键字搜索 + 若干计数接口的能力。
- **说明文档现状**：`basic-search`、`standards/statistics`、`statistics` 资源列表等可支撑**部分**看板；**未承诺**复杂报表与导出流水线。

### 1.5 不纳入本清单的已有能力（避免与合规模块重复）

- **合规审查 Excel 导出**在说明文档中有描述，产品归属更贴近合规评价/工作台；**不**作为标准库模块的「缺失项」罗列。

## 2. 查新服务模块

**详细展开**（现成可用接口清单、缺失接口用途与建议契约、与 [02-novelty-search.md](./02-novelty-search.md) 流程节点对应）：[查新模块-后端可用接口与待补充说明.md](./查新模块-后端可用接口与待补充说明.md)

### 2.1 查新任务实体与生命周期

- **任务列表**：分页、筛选（状态、时间、创建人等）。
- **任务详情**：稳定任务标识、当前阶段、**可恢复**的状态机（排队、解析中、待确认专用表、比对中、完成、失败等）。
- **任务控制**：取消、重试、失败原因展示（若产品需要）。
- **说明文档现状**：HTTP 章节**无**独立「查新任务」资源说明。

### 2.2 企标解析结果与查新专用表

- **专用表初稿**的查询、保存草稿、编辑后提交、确认进入比对（及确认前后版本）。
- **说明文档现状**：企标文件可上传并异步处理；**无**专用表资源的 REST 说明；WebSocket 虽有说明，**未约定**查新专用消息类型与载荷结构。

### 2.3 比对流水线与进度

- **逐条引用标准**与后端批处理编排对应的**可查询进度**（阶段、百分比、当前处理条目标识）。
- **说明文档现状**：单条 `check-latest`、批量 `batch-fuzzy-check` 存在；**整条流水线任务级进度**未在文档中体现（若仅依赖 WS，需契约）。

### 2.4 查新报告（PDF）与归档

- **查新结论 PDF** 的生成、存储、按任务下载、权限控制。
- **历史归档**：按任务、时间、企业等维度的**检索与再次下载**。
- **说明文档现状**：**无**查新 PDF 专用说明；合规类 Excel 与查新 PDF 不同，不能互相替代。

## 3. 企业档案模块（一企一库）

**详细展开**（弱相关说明、待补充建议契约）：[企业档案模块-后端可用接口与待补充说明.md](./企业档案模块-后端可用接口与待补充说明.md)

### 3.1 企业主数据

- **企业主档**的创建、查询、更新、删除。
- **列表**：分页与多条件筛选（企业名称、统一社会信用代码、状态等，字段以产品为准）。
- **说明文档现状**：**全文未出现**企业实体相关的 REST 描述。

### 3.2 主档与业务数据关联

- 企业与**企标专用表**、文档、监控对象等关联关系的**列表展示与维护**（一企一库主从结构）。
- **说明文档现状**：**无**上述关联的契约。

### 3.3 弱相关接口（不能替代档案模块）

以下接口在说明文档中出现，但语义为**企标号 / 引用 / 预警链**，**不能**替代「企业工商/合作客户主档」：

- 企标与国标的**映射保存**（主体是标准号维度）。
- **预警追溯**返回的「受影响」列表（示例为企标号维度，非企业库检索）。
- **规范性引用入库**（主体为企标与引用列表）。

## 4. 系统安全与审计模块

### 4.1 账号与 RBAC

- **用户**：创建、编辑、禁用/启用、重置密码、列表与搜索。
- **角色与权限**：角色 CRUD、权限项绑定（树或扁平资源，以产品为准）。
- **登录会话与前端可对接的鉴权模型**（若产品要求 SPA 走 Token 等，需与说明文档对齐）。
- **说明文档现状**：仅说明 Django **Admin** 使用 Session；**无**面向 SPA 的 `/api` 用户/角色管理契约。

### 4.2 系统级操作审计（全流程审计日志）

- **日志检索**：分页、多条件筛选（时间范围、操作人、模块、操作类型、IP 等）。
- **单条详情**：含**操作前快照 / 操作后快照**，支撑 **Diff** 展示（字段级，非模糊描述）。
- **导出**（若开放）：异步或同步、权限与二次确认策略。
- **只追加、不可删改**等语义若需对前端可见的**策略说明或错误码**。
- **说明文档现状**：**无**上述系统审计 REST 描述。

### 4.3 与「业务审核台」的区分（避免误用）

说明文档中的 **待审核指标 / 单条或批量审核** 属于**合规/指标业务流程**，**不是**需求文档 7.2 中的「登录、标准库修改、专用表修改 Diff、报告下载」等**系统级审计日志**能力；二者数据模型与界面目标不同，**不能**用业务审核接口替代系统审计模块。

## 附录 A：说明文档声明「当前不可调」的接口

《后端接口说明文档》**§5** 指出下列函数**未在 `urls.py` 注册**，前端**不得**按附录契约直接联调：

- 规范性引用检查类能力（文档中对应 `check_references` 等）。
- 指标评价类能力（文档中对应 `evaluate_indicators`、`evaluate_latest_indicators` 等）。

若产品需要上述能力，需后端**完成注册并更新说明文档**后，前端再对接。

---

## 附录 B：全局说明（仅列事实）

- 说明文档 **§1** 记载：多数业务接口鉴权为 **AllowAny** 或默认无 JWT；**Admin** 为 Session。**生产环境**若需与各模块菜单、按钮级权限一致，需有**统一、可文档化**的鉴权与权限模型，与当前说明文档的表述**尚未对齐**到可逐项实现前端路由守卫的程度（此处不展开方案）。
